# FanLite 1.0.0 — Notarized

<img src="https://raw.githubusercontent.com/stavitian/fanlite/v1.0.0-notarized/docs/icon.png" width="112" alt="FanLite icon">

This distribution update of FanLite 1.0.0 includes a new minimal app icon and an app **signed with Developer ID and notarized by Apple**. The app has Hardened Runtime, a secure timestamp and an attached notarization ticket. Its fan-control behavior is unchanged.

## Download and install

1. Download **FanLite-1.0.0.dmg** below, open it and drag FanLite into Applications. A ZIP is also available.
2. Open FanLite from Applications. It lives in the menu bar, with no Dock icon. With apps from identified developers allowed, no **Open Anyway** step is required. The usual confirmation for a downloaded app may still appear.
3. The first launch is read-only. Choose **Curva** or **Máx** to control the fans; macOS still asks for the administrator password. That permission is separate from notarization.

**Requirements:** Apple Silicon, macOS 14 Sonoma or later. Macs without fans are monitoring-only. The UI is in Spanish.

## Verified for these packages

- Valid Developer ID signature, Hardened Runtime and secure timestamp.
- Attached notarization ticket validated with `stapler`.
- Gatekeeper reports `accepted` and `source=Notarized Developer ID`.
- 52 existing simulator checks passed; these checks do not exercise physical fan control.
- SHA-256 checksums are provided in **SHA256SUMS.txt**.

This release contains the notarized distribution of app version **1.0.0**. Earlier unsigned/ad-hoc downloads remain in the previous release for history; use the assets attached here. Rebuilding from source requires signing and notarizing the new build separately.
